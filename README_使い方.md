# 静鉄ストア チラシ商品検索システム v2（PDF取り込み版）

v1（データ埋め込み版）とは別の、**チラシPDFをその場で取り込んで**使える
バージョンです。アップロードしたPDFをブラウザ内でJSONに変換し、検索・献立
提案を行います。変換したJSONは保存してGitHubなどで公開できます。

> v1（`app` フォルダ）はそのまま残してあります。v2 は `app-v2` フォルダです。

---

## 1. できること

- 📄 **チラシPDFの取り込み** … 「チラシ全店版 テキスト版.pdf」形式のPDFを
  アップロードすると、ブラウザ内で商品データ（JSON）に自動変換します。
- 🔍 **商品検索** … キーワード・「300円以下」などの話し言葉・部門・並べ替え。
- 📋 **詳細表示** … 販売期間（例：2026/10/17〜10/18）と税抜・消費税・税込の内訳。
- 🍳 **献立のヒント** … 取り込んだ食材で作れる料理を提案。
- ✓ **複数選択** … 選んだ商品の組み合わせで作れる料理を提案。
- 💾 **JSON保存** … 変換した `products.json` を保存。GitHub公開用に使えます。

すべてブラウザ内で完結し、PDFや入力データが外部に送信されることはありません。

---

## 2. 使い方

### 起動（ローカル）
- `起動する.bat` をダブルクリック、または `index.html` をブラウザで開きます。
- **重要**：一部のブラウザは `file://` で開くとPDF解析用のワーカーを
  ブロックします。もしPDF取り込みが動かない場合は、簡易サーバーで開いてください。
  - 例（Node）：このフォルダで `npx serve .` を実行し、表示されたURLを開く
  - 例（Python）：`python -m http.server` を実行し `http://localhost:8000` を開く
  - ※ GitHub Pages など**Web上に置けば常に正しく動作します**（推奨）。

### 取り込み
1. 画面の案内エリアに **PDFをドラッグ＆ドロップ**、または
   「📄 PDFを取り込む」からファイルを選択します。
2. 進捗バーが表示され、解析が終わると件数が表示されます。
3. そのまま検索・献立ヒントが使えます。

### 保存（GitHub公開用）
- 「💾 JSONを保存」で `products.json` がダウンロードされます。
- 取り込んだデータはブラウザ内（localStorage）にも保存され、次回開いたときに
  復元されます。別のPDFを取り込むと置き換わります。

### 既存JSONの読み込み
- 「📁 JSONを読み込む」で、以前保存した `products.json` を読み込めます。

## 3. 対応するPDFについて

- **テキスト版**（文字が選択・コピーできる）の「チラシ全店版 テキスト版.pdf」
  形式に対応しています。
- 画像だけのPDF（スキャン画像）は文字情報が無いため読み取れません。
- レイアウト（列の位置）がこの形式と大きく異なるPDFは、正しく取り込めない
  場合があります。その場合は `pdf-extract.js` の列定義（`COLS`）の調整が必要です。

この形式の既知のPDFでは、元のPython抽出と**同じ400件**を取り出せることを
確認済みです（部門内訳・価格・期間も一致）。

## 4. ファイル構成

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面本体（これを開く） |
| `app.js` | 検索・詳細・レシピ・複数選択・PDF/JSON入出力 |
| `pdf-extract.js` | PDF → 商品データ(JSON) 変換ロジック |
| `recipes.js` | レシピ・食材の知識ベース（v1と同一） |
| `icons.js` | 商品・料理の画像（絵文字）マッピング（v1と同一） |
| `vendor/pdf.min.js` | PDF.js 本体（オフライン同梱・Apache-2.0） |
| `vendor/pdf.worker.min.js` | PDF.js ワーカー（同梱） |
| `起動する.bat` | ブラウザで開くショートカット |
| `デプロイ手順.md` | GitHub Pages などへの公開手順 |
| `_verify_extract.js` | 開発用：Nodeで抽出結果を検証するテスト |

---

## 5. ご注意

- チラシ掲載情報を検索するデモです。価格・在庫のリアルタイム照会は行いません。
- 掲載期間が前後しているデータには「期間要確認」と表示します。
- 税抜・税込の片方しか無い場合、消費税は軽減税率8%での目安計算です。
- 献立ヒントは買い物の参考用で、正式なレシピの分量・調理法を保証しません。
